# 语音电话助手 (VoiceCallAssistant)

在 [VoiceClock](https://github.com/haoliying/VoiceClock) 的基础上扩展的语音控制版本：离线语音识别 + 离线语音合成，全部在本机完成，不联网（仅在首次启动时下载一次 TTS 模型）。

## 功能

1. **语音问时间**：说“几点了”，播报当前时间。
2. **来电报姓名**：姓名和号码都直接取自系统来电通知，不再查询通讯录，也不需要号码匹配。
   通知里有人名就播“张三来电话”；只有号码则把
   “一，八，五，六，零，一，八，一，一，四，五，来电话”整句合成一次
   （语感自然、有连读和气息），按号码缓存，同一号码再次来电直接播放；
   第一次来电时会在后台合成，约 1~2 秒，期间若超时会退回逐位拼接。
3. **响铃期间重复播报**：一轮播完隔 1.2 秒再播，直到系统报告铃声停止（对方挂断/超时/接通）才停，且每轮前都会重新确认通话状态，不会挂断后还在念。
4. **语音接听**：响铃时说“接电话”，自动接听。播报过程中说也能立刻打断播报并接听。
   优先点击来电通知上的“接听”按钮；没有该按钮时再依次尝试
   “系统接口 → 兼容接口 → 无障碍点击”，每一步都用通话状态验证是否真的接通
   （很多 ROM 上系统接口不报错但不生效）。
5. **语音挂断**：响铃或通话中说“挂断电话”，自动挂断。同样支持播报中打断。
6. **口令可配置**：三个口令都可以在界面里改，保存后立即生效，不需要重启服务。

## 首次使用

1. 安装 APK，打开应用，按提示授予权限（录音、电话状态、通话记录、接听电话等）。
   如果还没开“通知使用权”，应用会**自动跳到授权页**，请勾选“语音电话助手”。
2. 点“启动服务”，首次启动会下载约 116MB 的语音合成模型并解压，之后不再下载。
3. 建议再开启两个可选项（都会显示在界面的权限列表里）：
   - **通知使用权**（必开）：来电姓名和接听按钮都来自通知。
   - **无障碍服务**：系统没有公开的“挂断电话”接口，开启后可通过点击通话界面的挂断按钮兜底。

   日志里 `[来电] 权限 通话记录=… 接听=… 通知使用权=…` 会列出实际生效的通道；
   “复制日志”会把权限状态和完整的后台日志一起复制到剪贴板（界面没打开时的来电也有记录）。
4. 手机设置里把本应用加入电池优化白名单，避免后台被杀。

## 界面状态

服务的运行状态由同进程的服务实例直接判断，界面每次回到前台都会重新读取，不会再出现
“服务明明在跑却显示启动服务”的错位；用 Android 的绑定方式探测会顺带把服务创建出来，已弃用。

## 已知限制

- **通话中录音**：Android 10 以后第三方应用无法录制通话音频，接通后麦克风可能只返回静音。因此“挂断电话”在**响铃阶段**（拒接）最可靠，通话过程中能否识别取决于机型和 ROM。
- **挂断接口**：`TelecomManager.endCall()` 在部分 ROM 上只对默认拨号应用开放。本应用会依次尝试 `TelecomManager.endCall` → `ITelephony.endCall`（反射）→ 无障碍点击，日志里会显示实际生效的方式。
- TTS 只支持 arm64-v8a 真机，模拟器一般跑不起来。

## 构建

```bash
# 需要 Android SDK 34 + JDK 17/21
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

## 结构

| 文件 | 作用 |
| --- | --- |
| `VoiceService.java` | 前台服务：模型下载/解压、Vosk 识别、TTS 播报、来电监听 |
| `VoiceCommands.java` | 口令匹配（配置优先 + 同义词 + 容错） |
| `AppSettings.java` | 口令配置持久化 |
| `PhoneCallHelper.java` | 接听、挂断（通知按钮优先，多级兜底） |
| `CallAccessibilityService.java` | 可选的挂断兜底（无障碍点击） |
| `CallNotificationListener.java` | 来电姓名/号码来源，点击通知上的接听/挂断按钮 |
